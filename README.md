# Smart Bookmark

A full-stack bookmark manager with authentication, realtime updates, and row-level security.

Users can securely save, view, and delete personal bookmarks. Each user only sees their own data.

Live Demo: https://smart-bookmark-livid-ten.vercel.app

I hadn't used Supabase, deployed anything on Vercel, or developed in Next.js before
However, this was made much more doable using some tutorials and tools
